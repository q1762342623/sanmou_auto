# 功能一：邮件指令读取 → 跳坐标 → 最近同盟大营

> 实测环境：MuMu + adb，`127.0.0.1:16416`，分辨率 1600x900 横屏
> 实测时间：2026-11-20 13:59–14:33

## 1. 需求与实现结果

| 需求 | 实现 |
| --- | --- |
| 读取最近 10 条邮件 | `MailReader.read_latest(limit=10)`，按页签（同盟→法令）逐条点开 OCR |
| 关键字 1：集结 / 保护 → 行军过去 | `KEYWORD_RULES` 命中 → `MARCH`，跳坐标后由同盟大营「行军」承接 |
| 关键字 2：蹲坑 → 驻守 | 命中 → `GARRISON`，动作按钮候选 `驻守 / 调动` |
| 关键字 3：占领 / 攻占 / 梭哈 → 占领/攻城，不可攻占则行军 | 命中 → `OCCUPY`，按钮候选 `占领 / 攻城 / 攻占`；按钮不存在时记日志并改走大营路线 |
| 找到最新一条白名单内指令 | 邮件列表天然按时间倒序，取**第一条命中白名单且不在黑名单**的邮件 |
| 避开「有虫子」这类指令 | `BLACKLIST_KEYWORDS = ("虫子",)`，命中即整条跳过 |
| 跳到对应坐标 | 点正文里的绿色坐标 → 弹「是否跳转到坐标(x,y)」→ 确定 |
| 找到最近的可调动据点并点击 | 同盟 → 设施 → 同盟建筑（同盟大营）+ 同盟 → 城池（城/水寨/军港/民港），解析坐标并按距离取最小，点其坐标（跳转并选中），跳转后校验右侧有「调动」 |
| 截图留证 | 每一步落盘到 `screenshots/flow/`（JPEG，宽 1000，约 60–140KB） |

实测输出（2026-11-20 22:29）：

## 2. 用法

```bash
python -m sanmou_auto.flow_mail                    # 读 10 封，执行最新一条白名单指令（点最近同盟大营）
python -m sanmou_auto.flow_mail --limit 5
python -m sanmou_auto.flow_mail --tabs 同盟
python -m sanmou_auto.flow_mail --mode action      # 跳坐标后点 攻城/占领/行军/驻守 按钮（不点最终确认）
python -m sanmou_auto.flow_mail --all              # 逐条执行所有可执行指令
python -m sanmou_auto.flow_mail --dry-run          # 只读邮件并解析，不动地图
```

作为 skill 被上层 agent 调用：

```python
from sanmou_auto.flow_mail import MailFlow

flow = MailFlow()
mails = flow.read(limit=10, tabs=("同盟", "法令"))      # 列表按时间倒序
target = next((m for m in mails if m.intent.actionable), None)
if target:
    result = flow.execute(target, mode="camp")          # 跳坐标 -> 最近同盟大营 -> 截图
    print(result["ok"], result["camp"], result["shots"])
```

## 5. 踩过的坑（重要）

1. **邮件列表会记住滚动位置**，重新打开不是回到顶部 → 读取前必须 `scroll_to_top()`。
2. **新邮件到达会让列表整体位移**，记录的槽位失效 → 点开后校验标题/坐标，必要时本页 5 个槽位重新找。
3. **定位面板「同盟」页签内容会变**（最早是同盟大营列表，20 分钟后变成成员标记列表）→ 不作为主路线，只做兜底。
4. **大地图标签不能整屏送 OCR**：RapidOCR 会把长边压到 ~736px，小字全丢 → 必须 `ocr_tiled()` 切块（实测 `400x220` + 110 重叠）。
5. **表格类稠密文字同理**：切块太碎会把「(711,776)」拆成「(711」「1.776」→ 用大块 + 大重叠。
6. **右侧操作按钮整块 OCR 检测不到「攻城/行军」**，窄条裁剪后可以 → `ACTION_BOX` 只取 x 1075–1215。
7. **关闭定位面板会重新选中屏幕中心地块** → 截图顺序应为「点完大营再收面板」。
8. OCR 会把逗号识别成 `.` / `、` → 坐标正则分隔符 `[,，.、:：]` 全兼容。

## 7. 已知限制

- 占领/攻占的**最终确认（选择部队、出征）没有自动点**，`--mode action` 只点到确认面板前一步，避免误操作。
- 「集结/保护」要求行军时，若地块上没有「行军」按钮，只做到「跳最近同盟大营」，由操作者从大营行军。
- 邮件页签目前读「同盟」「法令」，其它页签（分组/系统/公告/收藏）默认不读。
- 同盟大营列表依赖「设施 → 同盟建筑」筛选；若该筛选条件变化，需更新第 4 节坐标。
