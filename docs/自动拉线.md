# 自动拉线（Auto Line）

> 功能命名：**自动拉线**。
> 一轮 = **邮件分析战场 → 调动据点 → 寻找敌方进攻 → 回家补兵**；
> 循环执行并统计每一轮、每个节点的真实墙钟耗时。

## 1. 四个节点

| 节点 | 做什么 | 关键实测坐标 / 判据 |
| --- | --- | --- |
| **邮件分析战场** | 打开左下「邮件」→「同盟」页签，读最近 N 封；关键字白名单（集结/保护/驻守/占领/攻占/梭哈/拉线…）解析动作 + 坐标；取最新一条可执行指令的坐标作为战场（附近 6 格内的指令算同一战场） | 邮件图标 (201,743)、同盟页签 x=355、正文坐标是绿色可点文字 |
| **调动据点** | 同盟 → 设施 →「同盟建筑」（同盟大营/堡垒）+ 同盟 → 城池（城/水寨/军港/民港），按到战场距离由近到远，跳转后校验右侧有「调动」再点；逐支派 部队1-4（出征前读「兵力 N」，不满先点白色补兵，补完仍低于门槛就跳过） | 调动按钮文字 ≈ (1132,386)；出征按钮本体 bbox 1283,779–1576,861；卡面状态条 y≈612–678 |
| **寻找敌方进攻** | 按邮件动作点 集结/攻占/行军（邮件执行不了就找红色敌对目标，视野无红敌再用「战报」绿色坐标）→ 出征 → 等战斗结束 | 右侧按钮列 x≈1075–1215；红色敌对目标只在 (250,140)-(1400,560) 中央区域找 |
| **回家补兵** | 回城（左下「回城」/城内「出城」同一点位 ≈ **(60,772)**）→ 城内「亲卫营」(1298,290) → 亲卫一/二/三 逐队读右侧「兵力 当前/上限」→ 不满才点「补兵/征兵」（不碰「建筑内自动补兵」开关）→ 出城回地图 | 亲卫部队页标题 OCR 常丢首字（「卫部队」）；页签在左侧 y≈190/280/355；兵力数值在 (1080,325)-(1600,400) |

## 2. 计时实现

- [`sanmou_auto/timing.py`](../timing.py)：`StepTimer.mark(name, kind, note, stage)`，
  每个 mark 记录「距上一次 mark 的墙钟秒数」；`stage` 就是上面四个节点，
  另有 `kind`（分析/执行/等待/准备/收尾）用于看时间花在「想」还是「点」上。
- [`sanmou_auto/flow_mobilize.py`](../flow_mobilize.py)：一轮流程，所有埋点都带 `stage`。
- [`sanmou_auto/battle.py`](../battle.py)：战斗子流程（`寻找敌方进攻`），回城/无目标收尾算 `回家补兵`。
- [`sanmou_auto/mobilize.py`](../mobilize.py)：调动面板子流程（`调动据点`）。
- [`sanmou_auto/home.py`](../home.py)：`回家补兵` 整段（回城 → 亲卫营 → 检查/补兵 → 出城）。
- [`sanmou_auto/flow_loop.py`](../flow_loop.py)：**自动拉线**循环 + 汇总，逐轮写 jsonl。

输出文件：

```
screenshots/flow/auto_line_<时间戳>.json     汇总（rounds / by_stage / by_kind / steps / detail）
screenshots/flow/auto_line_<时间戳>.jsonl    逐轮明细（边跑边写，可随时看）
screenshots/flow/auto_line_run.log           控制台日志（Tee-Object 落盘）
```

## 3. 实测方法

```bash
# 无人值守跑 1 小时（默认就是 60 分钟）
powershell -NoProfile -Command "python -u -m sanmou_auto.flow_loop --minutes 60 2>&1 | Tee-Object -FilePath screenshots/flow/auto_line_run.log"

# 跑完出报告（每轮四节点矩阵 + 各节点子步骤逐轮耗时）
python tools/auto_line_report.py
```

## 6. 已知瓶颈与优化

| 问题 | 现象 | 处理 |
| --- | --- | --- |
| 每轮重扫同盟据点列表 | 「定位最近可调动据点」单轮 **≈340s**（同盟建筑 + 14 屏城池列表 OCR） | 缓存据点列表，战场移动 ≤60 格直接复用（`CAMP_CACHE_RADIUS`）；选不中才重扫 |
| 世界聊天气泡挡住右侧按钮列 | OCR 把聊天句子当按钮，读不到「调动」→ 整轮失败（`no-troop-dispatched`） | ① 按「是否有深色底板」过滤聊天文字；② 读不到「调动」先等 3s 重试；③ 最终以「调动面板是否打开」为判据 |
| 回城点位偏右 | 原 `RETURN_HOME_POINTS` 首个点 (99,798) 点在图标外，回城无反应 | 改成 (60,772)，并加城内视角识别 + 「出城」回地图 |
| 设施页滑入动画期间点坐标不弹跳转框 | `select()` 偶发失败，白跑一轮 | 打开列表后等 0.8s；点坐标带 ±6px 偏移重试 3 次 |
| 邮件读取固定 ~55s/轮 | 10 封邮件逐封打开 + OCR | 现阶段保留（占单轮 <10%）；可 `--limit` 调小 |

## 7. 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--minutes` / `--seconds` | 60 / – | 运行时长 |
| `--gap` | 5 | 轮间隔 |
| `--limit` | 10 | 读同盟邮件条数 |
| `--troops` | 1,2,3,4 | 调动部队序号（范围固定 1-4） |
| `--min-strength` | 30000 | 补兵后仍低于它就跳过该队 |
| `--battle-timeout` | 900 | 等战斗结束/返回的秒数 |
| `--no-wait` | – | 不等战斗结束 |
| `--no-home` | – | 不做「回家补兵」 |
| `--no-strength-stop` | – | 4 队都补不满也继续跑 |
| `--max-fails` | 5 | 连续异常多少轮后停 |
