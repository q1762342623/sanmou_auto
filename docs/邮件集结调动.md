# 功能二：同盟邮件 → 找战场 → 最近同盟大营 → 调动 部队1-4 → 记录最后到达时间

> 实测环境：MuMu + adb，`127.0.0.1:16416`，1600x900 横屏
> 实测时间：2026-11-20 14:40–15:17

## 1. 流程

```
最近 10 条「同盟」邮件
      │  关键字白名单：蹲坑/占领/攻占/梭哈/集结/保护/集合/拉线…（黑名单：虫子）
      ▼
战场 = 最新一条白名单指令的目标坐标（并统计附近同一片战场的其它指令）
      │
      ▼
找离战场最近的「能调动」据点：同盟 → 设施 → 同盟建筑（同盟大营）+ 同盟 → 城池
（城 / 水寨 / 军港 / 民港），按坐标距离从近到远，点它的坐标 → 确认跳转（自动选中），
跳转后校验右侧有「调动」才算数（「无法入驻」的枢要之地跳过）
      │
      ▼
点「调动」→ 逐支选中 部队1-4 → 点金色「出征」
      │   每点一次都回读该部队卡状态：变成「行军 mm:ss / 调动」才算成功，
      │   否则重新定位按钮再点（最多 3 个候选点）
      ▼
到达时间 = 服务器时间 + 耗时（每支部队）
记录最后到达时间，写入 screenshots/flow/mobilize_<时间戳>.json
```

## 2. 用法

```bash
python -m sanmou_auto.flow_mobilize                 # 默认部队 1-4
python -m sanmou_auto.flow_mobilize --troops 1,2,3
python -m sanmou_auto.flow_mobilize --limit 10 --dry-run   # 只到「点选最近同盟大营」
```

Skill 形式调用：

```python
from sanmou_auto.flow_mobilize import MobilizeFlow

res = MobilizeFlow().run(limit=10, troops=(1, 2, 3, 4))
print(res["battlefield"], res["camp"], res["last_arrival"])
```

## 3. 「调动」面板实测结构（1600x900）

| 元素 | 位置 / 说明 |
| --- | --- |
| 面板标题 | 顶部居中「调动」 |
| 选点地图 | 上半屏；从大营点进来时目标已锁定为该大营 |
| 提示行 | y≈592「请选择出征部队　调动速度为行军速度的2倍」 |
| 部队卡状态条 | y≈612–678；5 张卡，状态文字在卡片左上（空闲 / 行军 mm:ss / 调动 / 停留） |
| 部队卡中心 | x = 115 / 323 / 539 / 760 / 960，y ≈ 700 |
| 体力 / 耗时 | 右下 y≈674 / 718，「耗时」是该部队单程用时 |
| **出征按钮** | 金色圆角块，可点区域在 **y≈745–775、x≈1300–1570**（实测 `(1430,760)` 生效） |

### 关键坑：出征不会关闭面板

点出征后**面板不关**，被派出的部队卡状态从「空闲」变成「行军 00:08:23」，到达后变成「调动」（驻扎）。
所以判断成功不能看「面板是否关闭」，必须**回读卡片状态**。

### 关键坑：金色 bbox 的几何中心是无效点

按颜色找金色块得到的 bbox 中心（实测约 y=820）点下去不会出征，反而会把面板关掉。
真正生效的是金色块**上缘往下约 20px**的位置（y≈760）。代码里 `find_exit_button()` 返回上缘点，
再配 `EXIT_FALLBACKS` 依次重试。

### 关键坑：按钮呈禁用态 = 该部队不能调动

可出征时金色像素约 1.6 万；被限制时只剩约 1.1 万（按钮变暗）。
实测中当其余 3 支部队都已派出时，剩下的那支点多少次都不会出征（系统保留留守），
日志会提示「出征按钮偏暗」。

## 4. 到达时间

- 「调动」面板打开后顶栏被压暗、读不到服务器时间 → 在**打开面板前**同步一次顶栏时间
  （[`ServerClock`](../mobilize.py)），之后用本机计时推算；OCR 失败则退化为本机时间
  （实测游戏内时间与本机东八区时间一致）
- 每支：`到达 = 派出时刻 + 耗时`
- 已在途的部队：状态里带倒计时，`到达 = 当前时间 + 倒计时`
- 已到达（状态为「调动/驻守」且无倒计时）不参与「最后到达」比较

## 7. 已知限制

- 只会读「同盟」页签（`--limit` 为读取条数）
- 战场取最新一条白名单指令的坐标；同一片（≤6 格）的其它指令只做统计，不分别执行
- 部队卡状态靠 OCR，偶发漏读会用第二次读取补齐；仍读不到时按「未知」处理并重试
- 若所有空闲部队都被派出，剩余部队可能被系统保留为留守，此时出征按钮为禁用态，属游戏规则
